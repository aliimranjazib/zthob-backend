# Chapter 9 — Glossary

| Term | Meaning |
|------|---------|
| **Mgask** | The tailoring platform described in this document |
| **Thobe** | Traditional Saudi men's garment |
| **Customer App** | Mobile app for people who order fabrics and stitching |
| **Tailor App** | Mobile app for shop owners, staff, and solo tailors |
| **Rider App** | Mobile app for delivery and measurement couriers |
| **POS** | Point of Sale — the in-shop counter where walk-in customers are served |
| **Walk-in** | Customer visits the tailor shop in person (no home delivery) |
| **Home delivery** | Order is picked up and delivered to the customer's address by a rider |
| **Home measurement** | A rider or tailor visits the customer to take body measurements |
| **Business** | The company entity owned by a multi-branch business owner |
| **Shop / Branch** | One tailor location; a business can have many shops |
| **Owner mode** | Tailor App entry for business owners managing multiple branches |
| **Staff mode** | Tailor App entry for employees working in assigned shops |
| **Solo tailor** | A tailor operating a single shop without a multi-branch business setup |
| **Express delivery** | Faster order turnaround offered by some shops for an extra fee |
| **OTP** | One-time password sent by SMS to verify phone number at login |
| **Work order** | Printable document with order details for the tailor production team |
| **Wallet** | In-app balance where tailor and rider earnings are recorded before payout |
| **Payout** | Request to transfer wallet balance to a bank account |
| **Style preset** | Saved combination of thobe style choices for quick reordering |
| **Family member** | A dependent (e.g. child) linked to a customer account with their own measurements |
| **Invitation code** | Code a tailor gives a rider to join their delivery team |
