# Chapter 3 — Customer App

The Customer App is how end users discover tailors, place orders, and follow their thobe from order to delivery.

## Getting started

- Sign in with a **phone number** and a one-time verification code (OTP)
- Set up a profile with name and preferred language (Arabic, English, or Urdu)
- Add delivery addresses (home, office, etc.) with one marked as default

## Discovering tailors and fabrics

| Feature | What the customer can do |
|---------|--------------------------|
| Browse tailors | Search and view tailor shops, ratings, and shop details |
| Browse fabrics | See each shop's fabric catalog with photos and prices |
| Save favorites | Bookmark fabrics to order later |
| Previous tailors | Quickly return to shops ordered from before |

## Ordering options

Customers can place different types of orders:

| Order type | Description |
|------------|-------------|
| **Fabric only** | Buy fabric without stitching |
| **Fabric + stitching** | Buy fabric and get a custom thobe made |
| **Stitching only** | Bring your own fabric; the tailor stitches it |
| **Home measurement** | Request a visit to take body measurements only |

## Customization

When ordering stitching, the customer can:

- Choose thobe style options (collar, cuff, pocket, etc.) with preview images
- Save favorite style combinations as presets for future orders
- Add **family members** (e.g. children) with their own measurements for multi-person orders
- Upload a reference image when providing their own fabric

## Payments and tracking

- See a full price breakdown before confirming (fabric, stitching, delivery, express fee if selected)
- Pay online by card or choose cash on delivery
- Pay a deposit now and the remaining balance later (partial payment)
- Track order status and, for home delivery, see the rider on a live map
- Receive push notifications when the order status changes

## After the order

- View order history
- Rate completed orders (stitching quality, on-time delivery, overall satisfaction)
- Benefit from a **one-time free home measurement** when placing a first eligible order

## Account management

- Update profile and addresses
- Manage family members and saved measurements
- Delete account if needed (data removed per platform policy)
